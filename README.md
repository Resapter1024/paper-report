# paper-report

面向课堂展示、学术报告等场景，在同一工作流中并行推进论文或研究材料的学习、报告准备与练习，以及 Slides、讲稿和学习／准备笔记的编写。

可边提问理解概念和推导，边完善报告内容、练习讲述与答疑。概念讲解和模拟问答也可直接用自然语言提出。

## 需要提供什么

- **研究材料与范围**：论文、自写研究报告或课程材料，以及需要汇报的部分。
- **展示要求**：听众基础、目标时长（是否含问答）、重点、语言和课程要求；缺项会通过提问补齐。
- **模板与输出**：指定模板和输出位置可选，无模板时使用内置样式；报告人信息由用户提供。
- 修改或导出已有报告时，提供现有文件和具体要求。

## 命令与输出

| 命令 | 功能 | 输出 |
|---|---|---|
| `$paper-report plan` | 确认听众、重点与结构 | 待确认问题、报告提纲、时间分配 |
| `$paper-report draft` | 编写报告文件 | Slides、讲稿和学习／准备笔记的源码与 PDF，或指定部分 |
| `$paper-report polish` | 修正文风、过度防御和提示语言混用 | 修订文件与简短修改说明 |
| `$paper-report check` | 只读检查内容、语言、排版和时长 | 按页列出的问题与修改建议 |
| `$paper-report export` | 导出已有讲稿 | Slides 对照版或纯文字版的源码与 PDF |

这些入口由 skill 识别，也支持自然语言调用。

编译 PDF 需要 XeLaTeX。附带 PowerShell 工具 `scripts/build-latex.ps1 -TexFile <文件.tex> [-Strict]`，输出 PDF 与编译日志；先编译 Slides，再编译嵌入 Slides 的讲稿。humanizer 为可选外部 skill。
